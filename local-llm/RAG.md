# 원문 검색·문맥 관리

현행 기준: 2026-09-20. 공개 Gemini 서비스와 로컬 Qwen 웹 대화가 공유하는 `ai/` 구현을 설명한다. 제품 범위는 연애에 한정하지 않는 일반 고민 상담이다. [최종 스펙](../spec/product-spec-final.md)을 기준으로 한다.

## 자료와 검색 범위

| 작가 | 수록 작품 | 검색 구간 |
|---|---:|---:|
| 제인 오스틴 | 7 | 5,351 |
| 윌리엄 셰익스피어 | 44 | 7,444 |
| 안톤 체호프 | 29 | 1,766 |

원본 13파일은 `data/originals/`에 보존하고 `ai/index/originals.sqlite3`에 작품·장면별 색인을 만든다. ‘전체 원문’은 수집된 판본의 작품 본문 전체이며, 작가의 모든 편지·습작·미완성작까지 수집했다는 뜻이 아니다. 체호프 자료는 러시아어 원작의 영문 번역판이다. [자료 목록](../data/originals/README.md), [체호프 판본](../data/originals/chekhov/README.md)을 참고한다.

## 현재 대화 처리

1. `ai/context.py`가 작가와 메시지 형식을 검증하고 `ai/prompts.py`의 관점·말투·답변 정책을 선택한다. `ai/situations.py`는 사용자가 선택한 주제와 입력의 단서를 검색어·응답 지침에 반영한다.
2. 한국어 주제 사전과 영어 단어로 먼저 검색한다. 짧은 후속 발화에는 이전 사용자 발화를 보완한다. 공용 `build_request()`는 `rewrite=False`이므로 공개·로컬 웹 대화 모두 검색어 생성용 LLM 호출이 없다.
3. SQLite FTS5 Porter 어간 처리와 BM25로 선택한 작가를 검색한다. 특정 작품을 명시하면 범위를 좁힌다. 안전 대응이 우선인 입력은 검색을 생략한다. 연애 단서는 일부 후보에 15% 가산점을 주지만 다른 고민을 차단하지 않는다.
4. 최대 3개 비중복 구간을 고른다. 다른 작품 후보의 관련도가 다음 후보의 80% 이상이면 다양성을 우선한다. 작품별 동일 비율을 보장하지 않는다.
5. 최근 최대 6개 대화 쌍과 최신 질문, 지침, 원문을 추정 3,200토큰 안에 구성한다. 최신 질문을 유지하고 공간이 허용되는 최근 대화부터 보존한다. 오스틴은 후속 대화 공간을 위해 원문을 최대 1개 전달한다. 예산에 맞지 않는 원문은 제외한다.
6. 모델은 상담 본문을 생성한다. 공개 서버는 입력의 보수적 상한도 별도로 검사하고 Redis 예산을 예약한 뒤 Gemini를 한 번 호출한다.
7. 조언 턴에는 실제 전달 원문에서 검증한 인용을 붙일 수 있다. 공개 서버는 번역 캐시가 있을 때만 표시한다. [인용 정책](VOICES-AND-QUOTES.md)을 참고한다.

공개·로컬 웹의 별도 기억 저장은 비활성화되어 있다. 날짜를 넘어 브라우저에 남은 최근 대화가 포함될 수 있지만 오래된 대화를 자동 요약하거나 장기 기억으로 저장하지 않는다. 공용 모듈에 남은 기억 입력 지원은 공개 서비스의 활성 기능이 아니다.

## 파일과 재현

프로젝트 루트 `jane/`에서 실행한다.

```sh
python -m ai.retrieval
python -m ai.retrieval --rebuild
python -m ai.retrieval --author william --query '가족의 기대 때문에 선택이 어려워요'
python -m pytest local-llm/test_retrieval.py local-llm/test_quotations.py -q
```

독립 검색 CLI의 `retrieve()` 기본값은 `rewrite=True`다. 이 경로는 사전 검색이 실패한 한국어 입력에서 Ollama 검색어 변환을 시도할 수 있어 실제 웹 대화 경로와 다르다. 원문 추가 시 manifest와 판본별 분할 규칙을 점검하고 재색인·검색 검증 후 배포한다. 공개 빌드는 색인을 준비하고 요청 중에는 읽기 전용으로 사용한다.

- `ai/retrieval.py`: 판본 분할, 검색어 구성, BM25 검색, 출처 검증용 메타데이터.
- `ai/context.py`: 입력 검증, 최근 대화·원문 예산 구성.
- `ai/index/translations.sqlite3`: 작품 인용의 한국어 번역 캐시. 사용자 상담 본문 저장소가 아니다.
- 과거 고정 발췌와 실측 자료는 제거하고 [실험 요약](../history/experiment-summary.md)에 통합했다.

## 검증과 한계

회귀 검사는 수록 작품 검색, 본문 범위, 원문 행·해시 일치, 작가 격리, 후속 맥락, 인용 검증과 문맥 예산을 확인한다. 과거 실측의 주요 결과와 한계는 실험 요약에 남겼다.

현재 RAG는 키워드 검색이며 임베딩·벡터 DB·의미 재평가 모델은 없다. 검색 성공이 고민과의 의미적 적합성을 보장하지 않는다. 원문에서 확인된 인물의 말도 작가 개인의 신념과 동일하지 않다. 관련 장면의 누락과 모델의 해석 오류는 별도 품질 검토가 필요하다.
