# 작가 말투와 작품 인용

현행 기준: 2026-09-20. [작가별 상담 관점](AUTHOR-COUNSELING-V10.md), [최종 스펙](../spec/product-spec-final.md)과 함께 읽는다. 구현은 `ai/prompts.py`, `ai/quotations.py`, `app.py`에 있다.

## 말투와 답변 길이

- 오스틴: 교양 있고 정중한 말투. 기대·평판과 실제 행동을 구분하고 관계의 원인을 확인하는 질문을 하나씩 한다. 실제 작가를 빅토리아 시대 귀족이라고 소개하지 않는다.
- 셰익스피어: 고풍스러운 한국어 하오체. 욕망·두려움·자존심과 선택의 대가를 살핀다. 뜻을 이해할 수 있는 비유나 조어를 필요할 때 최대 하나 사용하며 실제 원문 어휘로 주장하지 않는다.
- 체호프: 짧고 건조한 반말 독백. 모순·아이러니와 작은 단서를 살피되 고통을 조롱하지 않는다. 매번 질문·실천 과제로 끝내지 않는다. 2~4문장·가급적 120자는 생성 지침이지 강제 글자 제한이 아니다.

기본 탐색 턴은 오스틴·체호프 128토큰, 셰익스피어 160토큰이다. 조언 턴은 오스틴·셰익스피어 400, 체호프 256토큰이다. 명시적인 조언 요청과 대화 맥락을 규칙으로 판단한다. 공개 Gemini 어댑터의 절대 상한은 500토큰이며 안전 대응은 문학적 연출보다 우선한다.

## 공개 서비스 인용 흐름

1. RAG가 선택하고 실제 모델 문맥에 포함한 구간만 인용 후보로 삼는다.
2. 모델은 상담 본문만 스트리밍한다. 영어 인용·번역·출처를 모델 본문에서 만들어내지 않도록 지시한다.
3. 조언 턴에서 `select_quote()`가 짧은 연속 구절을 고르고 원본과 대조한다. 영어 구절·작품명·위치는 서버의 원문 자료에서 얻는다.
4. `cached_translation()`에 한국어 번역이 있으면 `quote` 이벤트로 영어·한국어·작품 정보를 보낸다. 캐시가 없으면 추가 번역 API 호출 없이 생략한다.
5. 화면은 인용과 ‘참고한 작가의 작품’을 표시한다. 행 번호·파일 경로, 인용이 없다는 안내, ‘한국어 · 서비스 번역’ 라벨은 표시하지 않는다.
6. 조언 저장 시 인용도 브라우저에 임시 보관한다. 인용은 별도 사용자 기억으로 저장하지 않는다.

모든 답변에 인용을 붙이지 않는다. 번역 캐시는 `ai/index/translations.sqlite3`에 있으며 원문·위치·번역 정책 등에 따라 구분한다. 체호프의 영어 구절은 러시아어 원작의 영문 번역판이고 한국어는 그 판본에 대한 서비스 번역이다. 기계적 존재 검증은 의미 적합성이나 번역 정확성을 보장하지 않는다.

## 로컬 Qwen의 차이

`local-llm/web_server.py`도 조언 턴에만 인용을 처리하지만 캐시가 없을 때 `translate_quote()`가 Ollama로 번역할 수 있다. 따라서 공개 서버보다 추가 지연이 생길 수 있다. 로컬 CLI는 실험 도구로 인용 출력 조건이 웹과 동일하지 않을 수 있다. 과거 매 턴 번역·지연 결과는 [실험 요약](../history/experiment-summary.md)에 통합했으며 현재 공개 서비스의 동작으로 해석하지 않는다.

```sh
# jane/에서 실행
python -m pytest local-llm/test_quotations.py local-llm/test_retrieval.py -q
```
