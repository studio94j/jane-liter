# 세 마녀의 예언

현행 기준: 2026-09-20. 이전 포춘쿠키 콘셉트를 대체한다. [최종 스펙](../spec/product-spec-final.md)의 예언 기능과 일치한다.

## 화면과 진입

- 대화를 시작하면 ‘고민으로 불안한 당신, 예언을 받아보시겠어요?’ 제안 스낵바를 조건부로 표시한다. 대화 홈의 상시 버튼이 아니다.
- 날짜별 제안 중복을 제한한다. 받은 예언은 하단 ‘나의 기록 → 예언’에서 조회·삭제하거나 다시 받는다.
- 세 마녀 이미지와 흑백 UI를 사용한다. 생년월일·태어난 지역 입력 화면 다음에 세 줄의 예언, 작은 제안, 작품의 영어 구절·한국어 번역을 보여준다.
- 모든 작가의 작품을 후보로 삼는 콘셉트이며 맥베스의 대사만 사용하는 기능이 아니다.

## 공개 서버의 실제 동작

`POST /api/prophecy`는 `cloud/prophecies.json`의 원문 검증 카드 9개(작가별 3개)에서 추첨한다. 제외 목록을 적용한 뒤 가능한 작가와 해당 작가의 카드를 무작위 선택한다. 풀이 소진되면 직전 카드만 제외한다. 매번 원문 전체를 검색하거나 Gemini를 호출하지 않는다.

생년월일·지역은 API에 전송하지 않으며 결과를 계산하는 데 사용하지 않는다. 문학적 놀이이며 개인의 미래를 예측하는 기능으로 소개하지 않는다. 결과는 현재 브라우저에 임시 보관하며 영구 보관이나 계정 동기화를 보장하지 않는다.

## 수정 위치

- `proto/fortune.js`, `proto/styles.css`: 예언 입력·결과·재요청 UI.
- `proto/app.js`: 대화 내 제안 스낵바.
- `proto/prophecy-archive.js`: 브라우저 보관과 조회.
- `app.py`: 추첨 API와 요청 제한.
- `scripts/prepare_prophecies.py`: 카드 본문·번역·원문 대조 및 캐시 준비.

카드 수정은 `jane/`에서 `python -m ai.retrieval`로 색인을 확인한 뒤 `python scripts/prepare_prophecies.py`로 생성한다. 영어 인용의 원본 일치뿐 아니라 번역·예언의 의미도 검토한다. 로컬 `local-llm/prophecy.py`는 Qwen 생성 실험용으로 공개 카드 방식과 다르다.
