# Jane 최종 제품 스펙

기준일: 2026-09-20. 공모전 공개 서비스의 현재 구현을 기준으로 제품·메뉴·AI·운영 스펙을 통합한 최종본이다. 이전 버전의 기획을 대체한다.

## 1. 제품 정의

Jane은 제인 오스틴, 윌리엄 셰익스피어, 안톤 체호프의 작품 관점을 빌려 고민을 나누는 문학 기반 AI 대화 서비스다. 원티드 AI 공모전 심사위원과 일반 사용자가 운영자의 컴퓨터 상태와 관계없이 접속할 수 있도록 공개 배포한다.

- 상담 범위: 직장·진로·인간관계·가족·친구·연애·일상의 고민과 선택.
- 핵심 경험: 작가 선택 → 고민 대화 → 필요할 때 조언과 작품 인용 → 대화 이어가기 또는 기록.
- 부가 경험: 세 마녀의 예언, 하루 한 통의 부치지 않을 편지.
- 실제 작가의 발언·인격을 재현하는 서비스가 아니라 작품을 모티브로 한 가상의 AI 상담사다.
- 전문 상담·치료·위기 대응을 대신하지 않는다. 즉각적인 위험에서는 문학적 역할보다 현실의 안전 지원을 우선한다.

## 2. 작가별 관점과 대화

| 작가 | 상담 관점 | 말투와 진행 |
|---|---|---|
| 오스틴 | 인간관계의 기대, 반복 행동, 애정과 존중, 현실 조건, 부담의 불균형 | 정중하고 예리한 말투. 부족한 정보 하나씩 질문하고 확인된 사실을 바탕으로 관계 패턴과 현실적인 조언 제시 |
| 셰익스피어 | 욕망·두려움·자존심, 주어진 처지와 선택의 대가 | 고풍스러운 하오체. 이해 가능한 비유·조어를 필요할 때 사용. 미래가 정해졌다고 단정하지 않음 |
| 체호프 | 애정과 원망의 공존, 일상의 모순·아이러니, 사소한 단서 | 짧고 건조한 반말 독백. 사용자의 고통을 비웃거나 억지 희망·해결책을 강요하지 않음 |

작가 선택은 현재 브라우저에 유지한다. 작가의 숨은 의도나 사용자가 말하지 않은 상대의 심리를 사실처럼 만들어내지 않는다. 사용자의 최신 설명과 정정을 우선한다.

## 3. 메뉴 구조

하단 GNB의 1depth는 `대화 / 나의 기록` 두 개다. 기본 진입은 대화이며, 설정은 상단 앱바에서 접근한다.

| 1depth·공통 | 2depth | 3depth | 다음 동작 |
|---|---|---|---|
| 대화 | 대화 홈 | 고민 주제·추천 시작 문구 | 입력·전송·후속 대화 |
| 대화 | 답변 | 조언 저장 / 참고한 작가의 작품 | 기록 저장 / 원문 상세 |
| 대화 | 대화 메뉴 | 대화 기억 안내 | 현재 미지원 안내 |
| 대화 | 대화 메뉴 | 작가 설정·관점·작품 보기 | 선택 / 상세 / 작품·장면 조회 |
| 대화 | 대화 메뉴 | 새 대화 시작 | 확인 후 해당 작가의 대화 초기화 |
| 대화 | 제안 스낵바 | 세 마녀의 예언 | 생년월일·지역 입력 → 예언 |
| 대화 | 제안 스낵바 | 편지 남기기 | 오늘의 편지 작성 |
| 나의 기록 | 대화 기록 | 날짜·작가별 대화 | 상세 / 해당 작가와 대화 이어가기 |
| 나의 기록 | 대화 기록 | 저장한 책과 조언 | 조회 / 저장 해제 / 작품 상세 |
| 나의 기록 | 편지함 | 오늘의 편지 작성 | 작성·보관 |
| 나의 기록 | 편지함 | 편지 상세 | 조회 / 오늘의 편지 수정 / 삭제 |
| 나의 기록 | 예언 | 받은 예언·상세 | 구절 확인 / 다시 받기 / 삭제 |
| 상단 설정 | 나의 조언가 | 작가 선택·더보기 | 선택 유지 / 상세 바텀시트 |
| 상단 설정 | 대화 기억 | 기억 기능 안내 | 별도 기억 저장 미지원 |
| 상단 설정 | 기록 관리 | 편지 정책·전체 삭제 | 확인 후 삭제 |
| 상단 설정 | Jane 안내 | 처음 안내 다시 보기 / 서비스와 저장 안내 | 온보딩 / 안내 바텀시트 |

설정 하단에는 제작자 문의 이메일 `hemingway3988@gmail.com`을 안내하고 메일 작성 링크를 제공한다.

설정에서 돌아가면 진입했던 화면으로 복귀한다. 작가 상세는 더보기, 썸네일 더블클릭 또는 롱탭으로 연다. 상세 바텀시트의 제목·설명은 상단, 이야기 나누기 버튼은 하단에 고정하고 중간 내용을 스크롤한다.

## 4. 대화와 제안

- 사용자와 작가의 메시지를 위치·버블로 구분한다.
- 작가별 오프닝에는 작품 구절을 사용한다. 로딩 문구는 작가의 상담 성향을 반영한다.
- 입력은 한 번에 최대 2,000자. 답변은 스트리밍 표시하며 중단·오류·재시도를 처리한다.
- 날짜가 달라지면 구분선을 표시한다. 브라우저에 남은 최근 대화는 날짜를 넘어 문맥에 포함될 수 있다.
- 기본은 짧은 응답·후속 질문이며, 사용자의 조언 요청 등 규칙에 따라 조언 모드로 전환한다.
- 실제 작품 인용은 조건을 충족한 조언 턴에만 표시한다. 원문을 못 찾았다는 별도 주석은 표시하지 않는다.
- 출처 버튼은 ‘참고한 제인 오스틴/셰익스피어/체호프의 작품’으로 표기한다. 내부 파일 경로·행 번호는 사용자에게 노출하지 않는다.
- 예언 제안은 대화 시작 후 ‘고민으로 불안한 당신, 예언을 받아보시겠어요?’ 스낵바로 노출한다. 날짜별 중복 노출을 제한한다.
- 편지 제안은 해당 날짜에 완료된 작가 답변이 3개 이상인 등 조건을 충족할 때 노출한다. 오늘 편지가 있거나 생성·오류·안전 대응 중인 경우, 예언 스낵바가 있는 경우에는 노출하지 않는다.

## 5. 부치지 않을 편지

- 서울 시간 기준 하루 한 통, 본문 최대 100자.
- 공백·문장부호·줄바꿈도 포함한다. 유니코드 정규화와 가능한 환경의 글자 단위 분할을 사용한다.
- 대화 중 제안으로 이동하거나 편지함에서 독립적으로 작성할 수 있다.
- 대화에서 내가 한 말을 가져올 수 있다. 오늘 편지는 수정하고 과거 편지는 조회·삭제한다.
- 보관 전 초안은 현재 창에만 남고, 보관한 편지는 현재 브라우저에 임시 저장한다.
- 편지 작성·저장은 LLM 호출을 필요로 하지 않는다.

## 6. 세 마녀의 예언

세 작가의 작품 문장을 세 마녀의 예언 형식으로 제공하는 문학적 경험이다. 셰익스피어의 맥베스만 검색하는 기능은 아니다.

- 생년월일·태어난 지역을 입력하는 화면을 제공한다.
- 공개 서비스는 원문 검증된 준비 카드 9개에서 무작위 선택한다. 매 요청마다 LLM으로 생성하지 않는다.
- 입력한 생년월일·지역은 예언 API로 전송하지 않으며 실제 개인별 운세 계산에 사용하지 않는다.
- 최근 카드를 피하고 풀이 소진되면 직전 카드와 다른 결과를 우선한다.
- 받은 결과는 브라우저에 임시 보관하고 나의 기록에서 다시 조회·삭제할 수 있다.
- 로컬 Qwen 실험용 예언 생성과 공개 서비스 카드 추첨은 구분한다.

## 7. AI·RAG·문맥

- 공개 모델 기본값: Gemini `gemini-3.1-flash-lite`. 파인튜닝하지 않는다.
- 구성: 공통 안전·사실 원칙 + 작가별 관점·말투 + 상황 지침 + 관련 원문 + 최근 대화.
- 공용 구현은 `ai/`, 모델 통신은 `cloud/gemini.py`, 로컬 Qwen 실행은 `local-llm/`에서 관리한다.
- 수집한 오스틴 7작품, 셰익스피어 44작품, 체호프 29작품을 검색 대상으로 한다. 체호프는 러시아어 원작의 영어 번역판이다.
- SQLite FTS5/BM25 기반 키워드 검색이다. 현재 임베딩·벡터 DB는 사용하지 않는다.
- 한국어 고민의 주제·감정 단서를 영어 검색어로 연결한다. 공개 대화에서는 검색어 생성을 위한 추가 LLM 호출을 하지 않는다.
- 관련 원문 최대 3구간을 선정하며, 오스틴은 대화 문맥 확보를 위해 최대 1구간을 전달한다. 전체 작품을 매번 읽거나 균일한 비율로 참조하는 방식은 아니다.
- 최근 최대 6개 질문·답변 쌍을 후보로 프롬프트·원문과 함께 추정 3,200토큰 이내로 구성한다. 오래된 대화를 자동 요약해 보존하지 않는다.
- 짧은 응답 상한 128~160토큰, 조언 모드 256~400토큰. 모델 어댑터 절대 출력 상한은 500토큰이다.
- 인용은 서버가 원문에서 선택한다. 조언 턴에 검증된 구절과 한국어 번역 캐시가 있을 때만 병기하며 캐시 미스로 추가 번역 호출을 하지 않는다.
- 검색 실패 시 관련 작품을 참조한 것처럼 주장하지 않도록 프롬프트로 제한한다. 검색·해석·생성의 정확성을 보장하지 않는다.

## 8. 저장과 개인정보

회원가입·로그인 없이 사용한다. 대화·작가 선택·책과 조언·편지·예언은 현재 브라우저에 임시 보관하며 기기 간 동기화·영구 보관·복구를 보장하지 않는다.

장기 기억은 현재 비활성화되어 있다. 반복 정보 추출·자동 기억 갱신·별도 기억 저장을 하지 않는다. 서버는 이전 클라이언트가 보낸 기억도 비운다.

공통 안내:
- ‘기억은 별도로 저장되지 않습니다. 정식 서비스를 기다려주세요.’
- ‘정식 출시 전 체험 버전으로, 대화와 기록이 계속 보관되지 않을 수 있어요. 간직하고 싶은 내용은 따로 복사해 주세요.’

대화 요청 시 최근 대화를 Gemini로 전달한다. Redis는 익명 사용량·예산 관리를 위해 사용하며 대화 본문 저장소가 아니다. API 키·세션 서명 키·Redis 접속 토큰은 서버 설정에만 둔다.

## 9. 배포와 비용 통제

- 공개 주소: https://literary-consult.vercel.app/
- 기존 주소: https://jane-contest.vercel.app/
- Vercel 정적 화면 + FastAPI + Gemini + Upstash Redis.
- 모든 세션: 하루 20회·분당 3회. 심사위원도 동일한 공개 링크와 한도를 사용한다.
- IP 하루 한도: 100회. IP 분당 한도: 15회.
- 기본 전체 일일 횟수: 300회. 세션 동시 요청 1개, 전체 동시 요청 4개.
- 기본 모델 비용 예산: 전체 일 $0.30·월 $9. 환경 변수로 조절한다. 제공사 결제 한도나 호스팅 비용까지 보장하는 값은 아니다.
- 호출 전 비용 예약, 완료 후 실제 사용량 정산. 불확실한 실패는 예약 비용을 유지한다. Redis 장애 시 모델 호출을 중단한다.
- 별도 심사 초대 기능은 제거했다. 기존 심사 세션은 ID를 유지한 일반 세션으로 전환한다.
